PROJET PYTHON POO - GESTION DES ETUDIANTS
Version interface propre simple

Fichier principal : gestion_etudiants_interface_propre.py

Pour lancer le projet :
python gestion_etudiants_interface_propre.py

ou sur Windows :
py gestion_etudiants_interface_propre.py

Ce que contient le projet :
- une classe Etudiant ;
- une liste d'objets Etudiant ;
- une interface Tkinter propre ;
- un tableau des étudiants ;
- ajout, recherche, notes, moyenne, résultat, suppression ;
- sauvegarde et chargement dans etudiants.json.

Cette version est volontairement simple pour pouvoir l'expliquer facilement à l'oral.
