# Gestion des Étudiants

Application de bureau développée en Python permettant de gérer une liste d'étudiants : ajout, affichage, modification et suppression, avec une interface graphique et une sauvegarde automatique des données.

Projet réalisé dans le cadre de ma première année de Bachelor Informatique et Systèmes Digitaux à l'EPSI.

## Fonctionnalités

- Ajouter un nouvel étudiant
- Afficher la liste des étudiants enregistrés
- Modifier les informations d'un étudiant
- Supprimer un étudiant
- Sauvegarde automatique des données dans un fichier JSON

## Technologies utilisées

- Python 3
- Tkinter — interface graphique
- JSON — stockage des données

## Lancer le projet

1. Installer Python 3 si ce n'est pas déjà fait : https://www.python.org
2. Ouvrir un terminal dans le dossier du projet
3. Lancer l'application :

```
python nom_du_fichier.py
```

*(remplace `nom_du_fichier.py` par le fichier qui ouvre la fenêtre, par exemple `main.py`)*
